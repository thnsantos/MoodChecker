# MoodChecker

MoodChecker é um projeto de check-in emocional e de bem-estar, desenvolvido para registrar como a pessoa está se sentindo no dia a dia. A ideia é oferecer uma experiência simples, direta e visual, com perguntas rápidas e uma área para registrar pensamentos ou observações pessoais.

## Objetivo

O projeto foi pensado para ajudar pessoas a refletirem sobre:
- humor atual
- nível de energia
- concentração
- sensação geral do dia
- pensamentos que estão presentes naquele momento

Com uma proposta leve e funcional, o MoodChecker funciona como um mini diário de autoconsciência, ajudando na identificação de padrões emocionais ao longo do tempo.

## Funcionalidades

- tela de login simples e funcional
- formulário de check-in com perguntas curtas
- escala visual para avaliação do humor
- perguntas complementares sobre energia e foco
- campo para registrar pensamentos livres
- interação com JavaScript para mostrar e esconder etapas do formulário
- layout responsivo para diferentes tamanhos de tela

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

- `index.html` — estrutura da interface
- `styles.css/` — estilos do projeto
- `scripts.js` — lógica da interação do formulário

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Faça o login com matrícula e senha.
3. Responda as perguntas do check-in.
4. Escreva uma observação opcional.
5. Envie o formulário.

## Observação

Este projeto foi criado com foco em prática de desenvolvimento front-end, com atenção em layout, UX e lógica de interação. A estrutura foi pensada para ser simples, didática e facilmente expandível conforme novas funcionalidades forem adicionadas.
